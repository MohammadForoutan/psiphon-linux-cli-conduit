Psiphon CLI

Unofficial Psiphon VPN client for Linux and Windows — connect, disconnect, and monitor tunnel stats from the terminal.

GitHub repository Get started All options

Overview

Psiphon CLI wraps psiphon-tunnel-core and gives you a simple command-line workflow:

  • Choose a protocol mode and egress region
  • Start a local HTTP proxy on port 8081
  • Start a local SOCKS5 proxy on port 1081
  • View live stats and tunnel-core logs in other terminals

By default, proxies listen on 127.0.0.1 (this machine only). Use --enable-lan to share them with other devices on your network.

Requirements

  • Node.js 18+ (not required for the standalone binary)
  • psiphon-tunnel-core binary for your platform from psiphon-tunnel-core-binaries
PlatformBinary name
Linux x64psiphon-tunnel-core-x86_64
Windows 64-bitpsiphon-tunnel-core-windows-amd64.exe
Windows 32-bitpsiphon-tunnel-core-i686.exe

Place the binary in the project root, or pass --core <path> when connecting.

Install

From source

git clone https://github.com/MohammadForoutan/psiphon-linux-cli-conduit.git
cd psiphon-linux-cli-conduit
npm install

Global install

npm install -g .
psiphon-cli --version

Version output shows the git commit hash and date (e.g. 963c89a 2026-05-22).

Standalone binary (no Node.js)

See Build standalone binary. Copy dist/psiphon-cli (or psiphon-cli.exe) anywhere on your PATH.

Quick start

psiphon-cli connect
  1. Protocol — choose 1 auto, 2 conduit, or 3 direct
  2. Region — choose auto or pick a country code (e.g. US, DE, NL)
  3. Tunnel starts. Proxies: HTTP 127.0.0.1:8081, SOCKS 127.0.0.1:1081
  4. Press Ctrl+C in the connect terminal to stop

In another terminal:

psiphon-cli stats    # live dashboard
psiphon-cli logs     # tunnel-core JSON logs
psiphon-cli disconnect   # stop from another terminal

connect

Default command. Starts the tunnel and keeps running until you disconnect.

psiphon-cli
psiphon-cli connect
psiphon-cli connect -r DE
psiphon-cli connect -p socks5://127.0.0.1:10808
psiphon-cli connect --enable-lan
psiphon-cli connect --enable-timeout

Connect options

OptionDescription
-r, --region <code>Egress region (ISO country code). Skips the region prompt when set.
-p, --upstream-proxy <url>Route tunnel traffic through an upstream HTTP/HTTPS/SOCKS5 proxy.
--enable-timeoutUse psiphon-tunnel-core's establish-tunnel timeout. Off by default — keeps retrying until connected.
--enable-lanListen on all interfaces (0.0.0.0) so LAN devices can use the proxies. Off by default.

Global options

Available on every command:

OptionDescription
-c, --config-dir <dir>Config and data directory (see Configuration).
--core <path>Path to psiphon-tunnel-core binary.
-V, --versionShow git commit hash and commit date.
-h, --helpShow command help.

disconnect

Stops the running tunnel-core process.

psiphon-cli disconnect

Uses the PID file when available; otherwise finds and stops tunnel-core by process name.

stats

Live dashboard refreshed every 2 seconds.

psiphon-cli stats

Shows:

  • Connection status and protocol mode
  • Active tunnel protocol (e.g. FRONTED-MEEK-OSSH)
  • Uptime
  • HTTP and SOCKS proxy addresses
  • Client and egress regions
  • Download/upload speed and totals

logs

Stream JSON notices from psiphon-tunnel-core (pretty-printed).

psiphon-cli logs
psiphon-cli logs -n 100

Run in a separate terminal while connected. Logs reset each time you start a new connection.

refresh-server-list

Download the latest official Psiphon server list into your config directory.

psiphon-cli refresh-server-list

Useful when you have good connectivity and want a fresh cached list for later use on restricted networks.

Upstream proxy

Chain tunnel traffic through another proxy (corporate proxy, local SOCKS, etc.).

psiphon-cli connect -p http://proxy.example.com:8080
psiphon-cli connect -p socks5://127.0.0.1:1080
psiphon-cli connect -p http://user:pass@proxy:8080

Environment variable (used when the flag is omitted):

PSIPHON_UPSTREAM_PROXY=socks5://proxy:1080 psiphon-cli connect

Supported schemes: http://, https://, socks5://

LAN access --enable-lan

By default, HTTP and SOCKS proxies bind to 127.0.0.1 only. To allow other devices on your local network:

psiphon-cli connect --enable-lan

This sets ListenInterface: "any" in psiphon config (binds to 0.0.0.0).

Other devices should use your host's LAN IP:

  • HTTP: http://192.168.x.x:8081
  • SOCKS5: socks5://192.168.x.x:1081
Security: Anyone on your LAN can use the tunnel when LAN mode is enabled. There is no authentication on the local proxies. Open firewall ports 8081 and 1081 if needed.

Connection timeout --enable-timeout

By default, the CLI sets EstablishTunnelTimeoutSeconds: 0 so psiphon-tunnel-core keeps retrying until a tunnel is established.

Pass --enable-timeout to use the core's built-in establish-tunnel timeout instead (it may exit if no tunnel comes up in time).

psiphon-cli connect --enable-timeout

Configuration

Config is stored in psiphon.config inside your config directory:

OSDefault path
Linux~/.config/psiphon-cli/
Windows%LOCALAPPDATA%\psiphon-cli\

First run

  • Default config is copied from configs/psiphon.config
  • Bundled server list snapshot is copied to remote_server_list
  • On each connect, the CLI updates region, protocol limits, proxy settings, and a few runtime flags

Files in config directory

FilePurpose
psiphon.configMain Psiphon core configuration
remote_server_listCached official server list
stats.jsonLive stats (while connected)
psiphon.pidRunning tunnel-core PID
psiphon.logCurrent session log

Advanced users can edit psiphon.config directly. The CLI warns if the official server list URL and signature key are missing but still respects custom settings.

System-wide proxy

Point applications or the whole system at the local proxies:

  • HTTP proxy: 127.0.0.1:8081
  • SOCKS5 proxy: 127.0.0.1:1081

For full-device routing, use a system proxy tool or TUN app such as Karing with SOCKS profile socks://127.0.0.1:1081.

Standalone binary

Build a single executable with no Node.js dependency. Place the matching tunnel-core binary in the project root first.

PlatformCommandOutput
Linuxnpm run builddist/psiphon-cli
Windowsnpm run build:windist/psiphon-cli.exe

On first run, the bundled core binary is extracted to your config directory if needed.

cp dist/psiphon-cli ~/.local/bin/
psiphon-cli --version
